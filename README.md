<h1>🎬 Movie Finder</h1>


<h2>What is MovieFinder?</h2>
<P>Movie Finder is a web project designed to help users discover movies and TV shows, get information, and find suitable streaming services.</P>

<h3>🛠️ Technologies</h3>
<P>html Website Structure
css Design and Responsive Layout
js logic
TMDB API  Movie data and, where applicable, streaming service information
OpenAI API  AI Features for the Movie Finder Assistant
Supabase  Planned Server-Side Processing of AI Requests</P>


<h4>📌 Project Status</h4>
<P>Status: In development; duration: 3 weeks</P>

<P>⚠️ Important Note

Movie Finder is not a streaming platform.

You cannot watch movies or TV shows directly on Movie Finder. The website helps you discover movies and TV shows and find out where they are available.

Our goal is to help you find free movies and TV shows, as well as suitable streaming options.
